# 저장과 씬 전환

저장·불러오기·씬 이동 작업 시 읽는다. **현재 상태와 후속 설계를 구분하는 문서이며 저장 시스템 구현 완료를 뜻하지 않는다.**

## 현재 구현

빌드 첫 씬은 `Assets/Scene/MainMenuScene.unity`, 월드는 `Assets/Scene/GameScene.unity`다. VehicleSession이 세션 내 출전 차종 ID와 비동기 단일 씬 전환을 관리한다. WorldVehicleController는 카탈로그 프리팹 한 대를 생성하고 기존 배치 차량 두 대를 비활성화하며 카메라를 연결한다. 직접 GameScene을 실행할 때는 개발용 Simple Retro를 사용한다. 메뉴 복귀 버튼과 Esc를 제공한다. 사용법은 [VehicleSelection](VehicleSelection.md)을 따른다.

현재 Bootstrap·영구 저장·온라인 세션/소유권 서비스는 없다. 임시 출전 ID는 게임 재시작 시 초기화된다. 기존 OutdoorsScene 빌드 등록은 보존했다. 씬 경로/차량 필수 연결 오류와 중복 진입은 처리하지만 서버 접속·손상 저장 복구까지 구현된 것은 아니다.

이전 입력 명령·Contacts·연기·자국은 런타임 일시 상태다. 직렬화된 Inspector 값은 사용자 세이브 파일과 다르다.

## 후속 설계 기준 — 미구현 제안

2026-09-16 사용자가 게임 실행 → 메인 화면의 상점/차고/임무/이벤트 → 차량 썸네일 선택과 3D 미리보기·개조 → 월드 진입 흐름을 제시했다. 상세 요구와 구현 순서는 [MainMenuFlow](MainMenuFlow.md)를 따른다. 메인 화면 내부의 상점·차고는 공통 미리보기를 사용하는 UI 패널로 먼저 구성하는 것을 제안한다. 아래 초기 자료의 차고 별도 씬 제안보다 최신 사용자 흐름을 우선한다.

플랫폼 요구가 PC·Android 우선 크로스플레이로 확정되었다. 아래 저장 제안을 로컬 단독 플레이의 최종 권한 구조로 구현하지 않는다. 그래픽·음량·입력 같은 기기 설정과 공유 진행·재화·미션·보상의 저장 및 판정 주체를 분리해 설계해야 한다. 서버 판정을 우선 검토하되 상세 구조는 아직 미정이다. [플랫폼 기준](PlatformAndPerformance.md)을 참조한다.

사용자가 제공한 「씬_구성_저장_이동_최적화_설계안.md」의 방향을 요약한다. 다음 항목은 구현 착수 시 실제 요구와 함께 확정한다.

| 영역 | 제안 |
|---|---|
| 씬 구성 | 사용자에게 보이는 메인 화면과 월드를 분리. 메인 내 차고·상점 등은 UI 패널로 구성하는 것을 제안하며 상주 초기화 계층은 필요에 따라 도입 |
| 소유권 | 활동 씬은 차량·지역 객체를 소유하고 종료 시 구독·생성 작업·로딩 참조를 정리 |
| 차량 이동 | GameObject와 물리 연결 대신 차량 ID·장착·필요 상태 데이터를 전달 |
| 데이터 분리 | 읽기용 기본 정의, 영구 진행, 활동 상태, 순수 일시 상태를 구분 |
| 저장 | 별도 DTO·버전·단일 쓰기 큐·임시 파일·백업·복구를 설계 |
| 상태 연속성 | 씬 이동 자체가 HP·탄약 회복이나 중복 보상 정산을 발생시키지 않게 처리 |
| 카메라·입력 | 카메라·AudioListener·EventSystem 소유자를 정하고 중복과 이전 씬 참조를 해소 |
| 실패 처리 | 중복 전환 방지·로드 실패 복귀·취소·손상 저장 복구를 정의 |

Bootstrap 등 위 이름은 설계상의 이름이다. Addressables 같은 패키지가 설치되어 있거나 위 서비스가 존재한다고 가정하지 않는다. 미래 폴더·씬 이름은 실제 구현 시 ProjectMap에 추가한다.

## 착수 시 정할 사항과 검증

먼저 빌드 진입 씬, 저장 대상/제외 상태, 체크포인트 시점, 차고·월드 소유권, 전환 중 입력 차단과 복구를 정한다. 구현 후 차고↔월드 왕복, 재시작 복원, 중복 생성·중복 정산, 저장 손상·로드 실패, 카메라·입력 참조 정리를 확인한다.

기존 VehicleDrivingValidation은 저장·씬 전환을 검사하지 않는다. MenuValidation은 별도 복사본에서 두 차량 선택과 메뉴↔월드 왕복·카메라/입력 연결·중복 객체를 검사한다. 영구 저장은 미구현이므로 재시작 복원 검증은 아직 없다.
